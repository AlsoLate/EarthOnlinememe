## 简介

**地球Online** 是一款以「人生」为主题的文字 / 数值模拟网页游戏。玩家在游戏中「投胎」成为一名角色，随机获得性别、家境、体质与特质，然后在「亚洲 / 香港」服务器开启一段**依赖运气和金钱**的游玩旅程。

游戏以 3D 地球为背景，用「游戏化」的口吻调侃现实：把上学叫「教程」、把恋爱叫「任务」、把通勤叫「公共交通移动」、把台风停课叫「八号风球福利」。所有 UI、事件、任务、成就都围绕这套黑色幽默展开。

> 提示：**珍惜只有一次的游玩地球Online的机会。**

## 特色

- 🌍 **3D 地球主界面**：基于 Three.js 的真实地球渲染（昼夜贴图、水体贴图、云层、Fresnel 大气层、NASA GIBS 实时云图）。
- 🎲 **随机开局**：性别、家境、体质、特质随机生成，含「亚洲家长（地狱难度）」「ADHD」「ASD」等恶搞特质。
- 📋 **任务 / 成就系统**：拍拖、10km、放学快线、超车达人……任务带触发条件、成功率与警告提示。
- 🏪 **商店系统**：用「运气币」购买「增加智商发展速度」「减弱李氏力场」等奇葩道具。
- 🕰️ **角色历史时间线**：按年龄回放角色一生中发生过的关键事件。
- 🛒 **LuckyPay 支付弹窗**：恶搞第三方支付流程（余额不足 / 支付中 / 不设退款）。
- 👥 **其他玩家（多人）**：通过 MQTT 广播，在「其他玩家」面板查看其他在线角色的属性与历史。
- ⚙️ **「设置」页**：视角、分辨率、RTX 光线追踪、语音输入设备等，几乎所有选项都「无法更改」。
- 🚐 **独立小游戏**：`loadingbusdriving/index.html` 是一个独立的 Canvas 车辆行驶模拟（红色小巴 / 大巴）。

## 游玩流程

```
点击屏幕进入 → 开发商 Logo 启动画面 → 加载画面(随机提示 + 进度条)
      → 主菜单(开始 / 设置 / 关于 / 退出)
      → 服务器表(选择服务器，实际为随机分配)
      → 登录 或 注册(DNA 加密)
      → 出生点(亚洲 / 香港)
      → 角色生成(正在投胎…，随机属性 / 特质)
      → 角色信息页(属性 / 特质 / 解锁成就 / 角色历史 / 任务管理 / 商店 / 其他玩家)
```

## 技术栈

| 领域 | 使用 |
| --- | --- |
| 3D 渲染 | [Three.js](https://threejs.org/) r128 + OrbitControls |
| 实时通信 | [MQTT.js](https://github.com/mqttjs/MQTT.js) 4.3.7（`wss://broker.emqx.io:8084/mqtt`） |
| 图标 | [Iconify API](https://iconify.design/) + [lucide-static](https://lucide.dev/) |
| 音频 | 原生 `Audio`（点击音效 + 两首 BGM） |
| 贴图 | three-globe 地球贴图、NASA GIBS WMS 实时云图 |
| 数据 | 纯静态 JSON，前端读取 |

无构建步骤、无依赖安装，所有第三方库通过 CDN 引入。

## 本地运行

由于游戏会通过 `fetch` 读取同目录下的 JSON 数据，建议用本地静态服务器打开，而不是直接双击文件：

```bash
# 方式一：Python
python -m http.server 8000

# 方式二：Node.js
npx serve .
```

然后浏览器访问 <http://localhost:8000/>。

> 注：部分贴图 / 音频 / 图标托管在公共 CDN 上，**需要联网**才能完整加载。若只想看界面，直接双击 `index.html` 也可运行（部分资源可能加载失败）。
